This repository contains the files used to produce the figures shown in H. Bartel, M. Burger, and M.-T. Wolfram. Multi-Dimensional Opinion Formation, 2026. arXiv:2601.0 (https://arxiv.org/abs/2601.04074).
execute_differentdistances.jl gives Figure 4 and execute_lefttoright.jl gives Figures 5 and 6.
